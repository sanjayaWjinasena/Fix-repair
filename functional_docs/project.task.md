**Summary:**

<!-- SUMMARY:model:project.task -->
Extends the Field Service task that carries out the repair. The "Repair Diagnosis" tab (`x_studio_diagnosis_ids`, lines of Task Diagnosis) records condition, symptom, diagnosis, reason and resolution. It sits alongside Repair Reason, Priority, two repair images, the warranty card and related ticket information. Mark as Done (`action_fsm_validate`) creates a transfer that moves the item out of the Repair location and moves the ticket to Repair Completed. The "Tested OK" button (`_repair_studio_end_quick_repair`) does the same for quick repairs. Creating a task can move the ticket to Diagnosis. Writes sync the ticket's warranty status onto the sales order (`_sync_repair_flags`). Validation methods block progress when diagnosis lines or images are missing. Computed flags (Valid Confirm/Delivered/Invoiced SO, Material Availability, So Cancelled) control button visibility. `_get_view` adds warning banners and hides the View SO button on cancelled tickets.
