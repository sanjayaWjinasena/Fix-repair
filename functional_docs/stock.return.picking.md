**Summary:**

<!-- SUMMARY:model:stock.return.picking -->
Adapts the Return Products wizard used by the ticket's Receipt, Return and Dispatch actions. When the wizard is opened from a repair ticket, `default_get` and `_compute_moves_locations` fill in the return location. `_get_view` changes the form for the repair case. `_create_returns` names transfers from the per-warehouse `<WH>/RET/` sequence and uses `<WH>/PHAN/` for the placeholder delivery that a receipt is created from. On create/write, `_fix_repair_validate_return_location` checks that RUG and with-serial repairs return to the suggested location. Adds read-only helper fields: repair-type flags and Suggested Location for each company.
