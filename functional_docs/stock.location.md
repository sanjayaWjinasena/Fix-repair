**Summary:**

<!-- SUMMARY:model:stock.location -->
Adds a new location type, Repair (`usage='repair'`), used for the per-warehouse `<WH>/Repair` locations. It also adds role flags (Finished Good Location, Repair Factory Location, Repair Return Location, Temp Location), Return Receipt Location, Return Sequence, and three user lists that control which users may use a location (Users (Stock Location), Users (Internal Transfer), Users (Scope 7kpUe)). The repair ticket and transfer logic reads these fields to filter locations and validate users.
<!-- /SUMMARY -->
